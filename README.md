# 🎓 Final Year Project

## 🧤 Smart Tactile Glove for Deaf-Blind Two-Way Communication

A wearable assistive communication system developed as my **Final Year Project at HITEC University, Taxila**.

The system uses **ESP32-S3, flex sensors, an IMU, Bluetooth Low Energy, audio feedback, and haptic feedback** to create an alternative communication interface.

### 🔧 Technologies

`ESP32-S3` `C/C++` `Flex Sensors` `MPU6050` `BLE` `I²C` `UART` `ADC` `Haptic Feedback` `Finite State Machine`

### ✨ Key Features

* 🖐️ Finger gesture detection using flex sensors
* 📐 Hand movement/orientation detection using IMU
* 🧠 Real-time sensor fusion and signal processing
* 📡 Bluetooth Low Energy communication
* 🔊 Audio feedback
* 📳 Haptic/vibration feedback
* 🔤 Gesture-based letter selection
* 🔄 Multiple operating modes
* 📝 Word construction and editing
* ⚠️ Error handling and system feedback

### 🧩 System Flow

```text
User
  ↓
Hand Movement + Finger Bending
  ↓
Flex Sensors + IMU
  ↓
ESP32-S3
  ↓
Sensor Processing
  ↓
Gesture Recognition
  ↓
Letter / Command Detection
  ↓
Word Construction
  ↓
Audio + Haptic Feedback
  ↓
BLE Communication
```

**Status:** Completed and demonstrated during Final Year Project presentation and Open House.
